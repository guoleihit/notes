## Why

建立一个个人学习知识库：存放学习笔记，借助 AI 语义理解实现高效检索，并在持续深化某个主题时自动发现新旧笔记之间的关联。核心痛点有二——过去的笔记因工具/云服务而丢失（因此数据所有权是硬约束）；传统分类式组织成本过高，检索依赖手动维护的索引。

## What Changes

- 新增**笔记存储**能力：所有笔记以纯文本 Markdown 存放在本地，用 git 版本化，支持增量添加与修改已有内容（数据永不丢失，工具可替换）。
- 新增**语义检索**能力：通过变更检测（基于 git）识别改动的笔记，仅对增量/修改的内容重新生成向量，维护本地向量索引，提供语义搜索。
- 新增**关联发现**能力：新笔记入库或旧笔记修改时，计算与既有笔记的语义相似度，自动提示相关内容，支持主题深化。
- 引入可插拔的模型抽象层：embedding 与 LLM 接口暂时对接云端 API（OpenAI 兼容协议），未来可无痛切换到本地模型。

## Capabilities

### New Capabilities
- `note-storage`: 纯文本 Markdown 笔记的存储、增量添加、内容修改与 git 版本化。
- `semantic-search`: 基于向量索引的语义检索，含变更检测与增量索引。
- `note-association`: 基于语义相似度的笔记关联发现与推荐。

### Modified Capabilities

（无——本项目为新建，无既有能力。）

## Impact

- 新增依赖：向量存储（如 sqlite-vec / chromadb）、云端 embedding/LLM API 客户端。
- 新增工程结构：笔记库（Markdown + git 仓库）与检索层分离，检索层可替换。
- 不影响任何既有代码（当前仓库为空，仅含 OpenSpec 脚手架）。
