## Purpose

为个人学习知识库提供基于语义理解的检索能力，使用户无需精确关键词即可找到相关内容，并仅对变更的笔记增量更新索引。

## ADDED Requirements

### Requirement: 语义搜索
系统 SHALL 根据用户查询的语义返回相关的笔记，而非仅按关键词精确匹配。

#### Scenario: 语义相关匹配
- **WHEN** 用户输入一个自然语言查询
- **THEN** 系统返回语义上与查询相关、但不一定包含相同关键词的笔记

### Requirement: 增量索引更新
系统 SHALL 仅对新增或修改过的笔记重新生成检索索引，未变动的笔记无需重新处理。

#### Scenario: 修改后索引更新
- **WHEN** 用户修改了一篇已有笔记
- **THEN** 系统只更新该笔记对应的索引，其余笔记索引保持不变

#### Scenario: 新增后索引可检索
- **WHEN** 用户添加一篇新笔记
- **THEN** 该笔记在之后的语义搜索中可被检索到

### Requirement: 模型提供方可配置
系统 SHALL 允许通过配置指定 embedding 模型提供方，切换提供方后检索行为保持一致。

#### Scenario: 切换模型提供方
- **WHEN** 用户将 embedding 模型提供方从云端 API 切换为其他兼容提供方
- **THEN** 系统使用新提供方生成向量，语义搜索功能保持可用
