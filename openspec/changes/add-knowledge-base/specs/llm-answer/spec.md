## Purpose

为个人学习知识库提供问答能力，将检索命中的候选文档与用户问题一起交给大模型，由大模型基于笔记内容返回答案。

## ADDED Requirements

### Requirement: 基于笔记内容的问答
系统 SHALL 将关键词命中的候选笔记内容与用户问题一起提交给大模型，并返回大模型基于这些内容生成的答案。

#### Scenario: 检索并回答
- **WHEN** 用户输入一个问题
- **THEN** 系统先检索命中的候选笔记，再将其内容与问题交给大模型，返回大模型的回答

#### Scenario: 无候选文档
- **WHEN** 检索没有命中任何笔记
- **THEN** 系统提示未找到相关内容，而不是编造答案

### Requirement: 模型提供方可配置
系统 SHALL 允许通过配置指定大模型的提供方与模型名，切换提供方后问答行为保持一致。

#### Scenario: 切换模型提供方
- **WHEN** 用户将大模型提供方切换为另一个 OpenAI 兼容的服务
- **THEN** 系统使用新提供方生成答案，问答功能保持可用
