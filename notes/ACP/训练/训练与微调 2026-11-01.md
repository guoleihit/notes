## 一、题目 188（多选）

**题目：** 你负责的短视频平台在接入多模态技术后出现故障。

1. 用户输入“生成夏日海滩vlog背景”时，系统返回静态图片而非视频
    
2. 视频自动剪辑功能无法识别冲浪板等特定物体
    
3. 添加的AI解说语音与动画动作不同步  
    需要重点检查的技术环节是？
    

**选项：**

- A. 视频编辑时是否设置了正确的时间轴
    
- B. 图像理解模型可能缺少对特定场景的训练数据
    
- C. 仅使用了文生图模型来生成完整视频
    
- D. 语音合成模型采样率不合适导致视频音画不同
    

**答案：A、B、C**

**解析：**

- 故障1：要视频却返回静态图，说明可能只调用了文生图模型，未接入文生视频能力 → 选 C。
    
- 故障2：无法识别冲浪板等特定物体，说明视觉/图像理解模型对特定场景、物体训练不足 → 选 B。
    
- 故障3：语音与动画动作不同步，核心是音视频时间轴对齐问题 → 选 A。
    
- D 不选：采样率不合适主要影响音质、格式兼容等，通常不是音画不同步的核心原因。
    

**知识点扩展：**

- 文生图 ≠ 文生视频；多模态生成链路中需区分图像生成、视频生成、视频编辑、语音合成等环节。
    
- 音画同步主要检查时间轴、帧率、音频时长、对齐点、剪辑拼接。
    
- 视觉模型识别特定物体失败，常见原因是训练数据覆盖不足、类别不平衡、场景域差异。

## 二、题目 191（单选/多选语境）

**题目：** 以下哪种方式有助于在大模型多轮对话场景中，保障生成内容质量的同时，降低成本，并提升响应速度？

**选项：**

- A. 使用 Batch API
    
- B. 并行调用大模型 API
    
- C. 使用支持上下文缓存的大模型API
    
- D. 使用经过量化的模型
    

**答案：C、D；若只能选一个更优：C**

**解析：**

- C 上下文缓存：多轮对话中系统提示词、历史对话等大量重复，缓存可复用计算结果，直接降本提速，且通常不改变生成逻辑，对质量影响最小。
    
- D 量化模型：降低显存占用和推理计算量，能降本提速，但可能有精度损失，需评估任务适配性。
    
- A Batch API：适合离线批量处理，降本但不提升实时响应速度。
    
- B 并行调用：提升并发/吞吐，但可能增加成本，不直接保障多轮对话质量。
    

**知识点扩展：**

- 上下文缓存分为隐式缓存和显式缓存；主流平台如 OpenAI、Anthropic、Gemini、火山引擎、智谱等支持程度不同。
    
- 缓存通常要求固定内容放前面（系统指令、工具定义、知识库），变化内容放后面，以提高命中率。
    
- 量化适合推理部署降本，但需关注精度、硬件支持和任务效果。

## 三、题目 192（单选）

**题目：** 你使用阿里云百炼平台的通义千问API开发了聊天机器人，用户反馈：提问某地天气时模型总是无法回答。如何快速解决这个问题？

**选项：**

- A. 提前设置话术，在面对类似问题时可以直接将话术返回给用户
    
- B. 通过复杂的工程手段，对用户的输入提取关键词，集成第三方搜索引擎，并将搜索结果返回
    
- C. 给大模型（选项原文不完整）
    
- D. 设置 enable_search（联网搜索）参数，为通义千问 API 引入联网能力
    
- E. 在聊天界面显眼位置标注限制，不建议用户输入类似问题
    

**答案：D**

**解析：**

- 天气属于实时性信息，大模型知识有截止日期，直接回答不了。
    
- `enable_search=true` 可引入联网搜索，快速获得实时信息。
    
- A、E 是回避问题；B 工程量大，不符合“快速解决”；C 选项不完整，无法判断。
    

**知识点扩展：**

- 百炼中 `enable_search` 是扩展参数，OpenAI 兼容接口下 Python SDK 常通过 `extra_body` 传入。
    
- 并非所有模型都支持联网搜索；多模态模型可能需要走多模态接口，部分模型对搜索策略有限制。
    
- 支持联网搜索的模型覆盖 Qwen3.5/3.6/3.7/3.8 多个系列及部分语音、第三方模型，但需以官方文档为准。

## 四、题目 195（多选）

**题目：** 以下哪些任务可以使用 ffmpeg 完成？

**选项：**

- A. 提取视频中的音频。
    
- B. 调整视频的分辨率。
    
- C. 训练一个语音识别模型
    
- D. 将多个视频片段合并成一个视频。
    
- E. 为视频添加水印。
    
- F. 转换视频格式（例如 mp4 到 avi）
    

**答案：A、B、D、E、F**

**解析：**

- A 可提取音频，如 `-vn`。
    
- B 可用 `scale` 滤镜调整分辨率。
    
- D 可用 `concat` 合并视频。
    
- E 可用 `overlay` 添加水印。
    
- F 是 FFmpeg 核心转码功能。
    
- C 不选：FFmpeg 是音视频处理工具，不负责训练语音识别模型。
    

**知识点扩展：**

- FFmpeg 是开源多媒体框架，包含 `ffmpeg`、`ffplay`、`ffprobe` 等工具及 `libavcodec`、`libavformat`、`libavfilter` 等库。
    
- 常用于转码、剪辑、合并、提取、加水印、推流、分析媒体信息等。
    
- 模型训练需深度学习框架和训练数据，不是 FFmpeg 的职责。

## 五、题目 196（多选）

**题目：** 在监控大语言模型训练性能时，哪些指标是常用的？

**选项：**

- A. 训练时间
    
- B. 生成速度
    
- C. batch size
    
- D. 精准率
    
- E. 损失函数值
    
- F. 准确率
    

**答案：A、E、F**

**解析：**

- A 训练时间：反映训练效率。
    
- E 损失函数值：监控收敛的核心指标。
    
- F 准确率：可作为验证/评估指标观察任务表现。
    
- B 生成速度更多反映推理阶段性能。
    
- C batch size 是超参数/配置，不是监控指标。
    
- D 精准率是任务评估指标之一，但不是通用训练性能监控的默认必选。
    

**知识点扩展：**

- 训练监控核心还包括学习率、吞吐、每步耗时、显存占用、是否 NaN/震荡、验证 loss 等。
    
- 训练 loss 可高频记录，验证 loss 通常按 epoch 或定期评估。
    
- 准确率和精确率不同：准确率看整体判对比例；精确率看预测为正中有多少真正为正。

## 六、题目 199（多选）

**题目：** 阿里云内容安全服务支持的自定义配置包括？

**选项：**

- A. 修改模型架构参数
    
- B. 创建私域关键词词库
    
- C. 配置审核规则模板
    
- D. 设置风险等级阈值
    

**答案：B、C、D**

**解析：**

- 常见能力包括文本、图片、视频、语音等多模态内容审核。
    
- 企业可结合业务场景配置私域词库和审核模板，平衡召回与误杀。

## 七、题目 200（多选）

**题目：** 百炼平台的核心优势包括？

**选项：**

- A. 独占实例动态调整资源
    
- B. 闭源模型高效部署
    
- C. 完全开源代码控制
    
- D. 零代码自动微调
    
- E. 降低召回文本段的中文含量
    

**答案：A、D**

**解析：**

- A 支持吞吐预留、PTU 专属部署、按需扩缩容等，保障稳定性和成本。

- E 不是百炼功能；RAG 中建议查询与文档语言一致，而非刻意降低中文含量。
    

**知识点扩展：**

- 百炼定位是多模型统一接入与全链路开发平台，覆盖模型调用、微调、部署、RAG、应用编排等。
    
- 独占实例/专属部署适合高稳定、高并发、数据隔离要求场景。
    
- 零代码微调降低模型定制门槛。

## 八、补充问答知识点

### 1. C 和 D 只能选一个，为什么选 C？

- C 上下文缓存更贴合“多轮对话”，直接复用重复上下文，降本提速且对生成质量影响最小。
    
- D 量化可能带来精度损失，需要额外评估模型和任务适配性。
    

### 2. 大模型 API 有区分支持缓存和不支持缓存吗？

- 有。不同厂商、不同模型支持程度不同。
    
- 常见分为隐式缓存（自动、不保证命中）和显式缓存（手动配置、确定性命中）。
    
- OpenAI、Anthropic、Gemini、火山引擎、智谱等均有不同缓存机制。
    
- 设计提示时应把固定内容放前面，变化内容放后面。
    

### 3. 千问哪些模型支持联网搜索？

- 主流 Qwen3.5 及以上系列广泛支持，包括 Max/Plus/Flash 等，部分 Omni、语音模型和第三方模型也支持。
    
- 需注意：多模态模型可能要走多模态接口；不同模型支持的搜索策略不同；以官方文档为准。
    

### 4. FFmpeg 是什么？

- 开源多媒体框架，音视频处理“瑞士军刀”。
    
- 包含命令行工具和开发库，支持转码、剪辑、合并、提取、加水印、推流、分析等。
    
- 不负责模型训练。
    

### 5. 准确率和精确率的区别

- 准确率 Accuracy = 预测正确数 / 总样本数，看整体判对比例。
    
- 精确率 Precision = TP / (TP + FP)，看预测为正的样本中有多少真正为正。
    
- 类别不平衡时，准确率容易虚高，应结合精确率、召回率、F1。
    

### 6. 损失函数值每一轮都监控吗？

- 训练 loss 可每个 step 或每 N 步记录，至少每个 epoch 汇总。
    
- 验证 loss 通常每个 epoch 或定期评估。
    
- 重点是观察是否稳定下降、是否过拟合、是否 NaN/突增/震荡。
    

### 7. 为什么监控准确率而不是精确率？

- 上一题选的是准确率，不是“只监控精确率”。
    
- 准确率更通用直观；精确率依赖正类定义和阈值，适合特定任务和类别不平衡场景。
    
- 大模型训练监控核心其实是 loss、学习率、吞吐、耗时、显存等，准确率/精确率属于任务评估指标。
    

### 8. 千问是开源还是闭源？

- 千问是“开源 + 闭源”并行体系。
    
- 开源：开放模型权重，可本地部署、微调、二次开发，如多个 Qwen 系列和专项模型。
    
- 闭源：旗舰高性能模型通过 API 调用，不公开权重，如 Qwen-Max、部分 Omni 模型等。

## 九、今日总结

1. **多模态故障排查**：区分文生图/文生视频，关注视觉模型训练数据覆盖、音视频时间轴对齐。
    
2. **大模型降本提速**：多轮对话优先考虑上下文缓存；量化可作为推理部署优化手段，但注意精度。
    
3. **实时信息问答**：天气等时效问题应启用联网搜索 `enable_search`，并确认模型支持。
    
4. **FFmpeg**：擅长音视频处理，不负责模型训练。
    
5. **训练监控**：核心看 loss、训练时间、验证指标；batch size 是配置，生成速度偏推理。
    
6. **评估指标**：准确率看整体，精确率看正类预测质量；类别不平衡时不能只看准确率。
    
7. **内容安全**：自定义能力集中在词库、规则模板、风险阈值，不能改模型架构。
    
8. **百炼平台**：核心优势包括独占实例资源调整、零代码微调；不是完全开源，也不是专门“闭源模型高效部署”。
    
9. **千问生态**：开源与闭源并行，开源做生态和私有化，闭源 API 提供旗舰性能。
