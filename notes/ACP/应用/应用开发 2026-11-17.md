## 一、易错/争议题重点报告

### 1. 第165题：流式对话 `LLM_MODEL.stream_chat(messages)` 适用场景

**题目：** 以下哪些场景适合使用流式对话 `LLM_MODEL.stream_chat(messages)`？  
A. 实时聊天机器人，需要立即响应用户输入。  
B. 需要对大模型输出进行实时监控和干预的场景。  
C. 用户需要快速获得初步结果，后续可以继续补充信息完善结果。  
D. 只需要一次性返回完整结果的简单任务，例如翻译单个单词。  
E. 需要处理长文本输入的场景，可以逐步返回结果，避免超时。

**参考答案：** 严格口径选 **A、B、C**；宽松口径可能选 **A、B、C、E**。  
**易错点：** E 的“长文本输入”表述不严谨。流式主要流的是**输出**，不是输入。

**选项解析：**

- A 正确：实时聊天需要逐段返回，降低等待感。
    
- B 正确：流式输出便于实时观察、中断和干预。
    
- C 正确：先返回初步结果，再继续完善，符合流式交互。
    
- D 错误：简单一次性任务流式收益很小。
    
- E 有瑕疵：后半句“逐步返回结果，避免超时”符合流式输出价值，但“长文本输入”说法不准确。更准确应是“长文本**输出/生成**场景”。
    

**知识点：** `stream_chat` 的核心是**流式输出**，即模型生成内容逐步返回，而不是一次性返回完整结果。

**扩展讲解：** 流式适合低延迟交互、长回答生成、可中断/可监控场景；不适合短小、一次性、无需等待感优化的任务。考试中遇到“流式输入/输出”要区分清楚。

### 2. 第152题：文档审阅中为什么不建议一次输出所有结果

**题目：** 在文档审阅中，为什么不建议一次输出所有的结果？  
A. 只需关注营销表达  
B. 大模型可能会漏掉一些错误  
C. 内容错误不需要处理  
D. 信息量过大，难以理解  
E. 直接提问：“请优先将NSC 翻译为神经干细胞”

**参考答案：** **B**；若为多选，可考虑 **B、D**。  
**易错点：** D 也有一定合理性，但核心原因是模型在一次性处理大量、多类型问题时容易遗漏。

**选项解析：**

- A 错误：文档审阅不只关注营销表达。
    
- B 正确：一次性输出所有结果时，模型注意力分散，容易漏掉部分错误。
    
- C 错误：内容错误当然需要处理。
    
- D 部分合理：信息量过大确实影响理解和阅读，但不如 B 贴近“模型识别遗漏”的核心。
    
- E 错误：这是具体指令示例，不是原因。
    

**知识点：** 复杂文档审阅应**分类型、分批次、分步骤**处理，并做汇总复核，降低漏检率。

**扩展讲解：** 实际工程中更稳妥的流程是：定义问题类型 → 分段/分类型识别 → 汇总去重 → 规则或人工复核。单次“全量输出”容易受输出长度、注意力分配和类型边界影响。

### 3. 第169题：阿里云支持的模型部署平台

**题目：** 阿里云支持的模型部署平台包括？  
A. 云服务器ECS  
B. 函数计算FC  
C. 人工智能平台PAI-EAS  
D. 大模型服务平台百炼  
E. 创建新的 Acsictant

**参考答案：** **A、B、C、D、E**。  
**易错点：** E 题干疑似笔误，应为 **ACS（容器计算服务）** 相关表述。

**选项解析：**

- A 正确：ECS/GPU 云服务器可用于自建模型部署。
    
- B 正确：函数计算 FC 提供 Serverless GPU，可部署大模型推理服务，但需注意冷启动和超时限制。
    
- C 正确：PAI-EAS 是模型在线服务部署平台。
    
- D 正确：百炼是全托管大模型服务平台。
    
- E 按 ACS 理解正确：阿里云容器计算服务 ACS 支持 Serverless 容器化模型推理部署。若题干确为“Acsictant”则属于笔误。
    

**知识点：** 阿里云模型部署覆盖 IaaS（ECS）、Serverless（FC/ACS）、AI 平台（PAI-EAS）、全托管 MaaS（百炼）等多层级。

**扩展讲解：** FC 能部署大模型，但适合低频、弹性、可容忍冷启动的场景；高并发低延迟常驻服务更适合 PAI-EAS 等。

### 4. 第148题：检测文档中营销性表达的方法

**题目：** 在检测文档内容中是否存在营销性表达时，下列哪种方法可以更全面地识别问题？  
A. 识别所有内容错误的部分  
B. 让大模型自动修改内容  
C. 逐条单独识别营销词汇  
D. 一次性生成所有类型的识别结果

**参考答案：** **D**。  
**选项解析：**

- A 错误：内容错误不等于营销表达。
    
- B 错误：修改不等于识别。
    
- C 部分有效但局限：只覆盖词汇层面，容易漏隐性营销。
    
- D 更全面：可覆盖显性词汇、隐性表达、语境和句式等多类型。
    

**知识点：** 营销表达检测要综合**词汇、句式、语气、语境、隐性营销**。  
**扩展讲解：** D 也有遗漏风险，实际工程应“分类型识别 + 汇总复核”，但选择题中相较 C 更全面。

### 5. 第151题：自定义 LangChain LLM 对象的核心要素

**题目：** 如果想要自定义 LangChain 的 LLM 对象，理论上只需要准备以下哪个要素？  
A. 一个 API Key  
B. 一个 Model name  
C. 一个 JSON，直接加载即可  
D. 一个输入为字符串，输出为字符串的函数

**参考答案：** **D**。  
**选项解析：**

- A、B 是调用具体模型服务时的参数，不是自定义 LLM 对象的本质。
    
- C 错误：JSON 直接加载不是自定义 LLM 的核心。
    
- D 正确：核心是实现类似 `_call(prompt: str) -> str` 的字符串输入输出逻辑。
    

**知识点：** LangChain 自定义 LLM 需继承 `LLM`，实现 `_call` 和 `_llm_type`。  
**扩展讲解：** 可选实现 `_stream` 支持流式、`_acall` 支持异步、`_identifying_params` 输出参数信息。

### 6. 第155题：不定期文档分析任务的最优计费方式

**题目：** 某企业需要部署一个大模型，不定期自动地分析现有的产品文档，并产出改进建议，以下哪一种计费方式可以在满足业务需求的同时最大化降低运行成本？  
A. 通过按量付费方式创建 GPU 资源  
B. 使用抢占式实例（Spot Instance），同时设计好任务中断的自动恢复机制  
C. 购买显卡并搭建本地服务器  
D. 通过预付费（包年包月）方式创建 GPU 资源

**参考答案：** **B**。  
**选项解析：**

- A 灵活但单位成本高于 Spot。
    
- B 最省成本：抢占式价格低，配合中断恢复机制可满足可中断批处理任务。
    
- C 前期投入大、运维成本高。
    
- D 适合长期稳定高负载，不适合不定期任务。
    

**知识点：** 抢占式实例适合**无状态、容错、可中断**的批处理任务；按量付费适合波动但需稳定性的临时资源。  
**扩展讲解：** 抢占式可能被回收，需设计检查点、重试、任务队列和自动恢复。

### 7. 第166题：用户输入清洗和预处理以提高安全性

**题目：** 以下哪些代码片段可以有效地对用户输入进行清洗和预处理，以提高大模型应用的安全性？  
A. 将用户输入中的 emoji 表情符号替换为文本描述。  
B. 将用户输入转换为小写。  
C. 限制用户输入的长度。  
D. 去除用户输入中的 HTML 标签。  
E. 将用户输入中的 URL 替换为特殊的占位符。  
F. 先把英文全部翻译为中文。

**参考答案：** **C、D、E**。  
**选项解析：**

- C 正确：防止超长输入、资源消耗和注入绕过。
    
- D 正确：降低 XSS、HTML 注入风险。
    
- E 正确：对 URL 做风险隔离，降低恶意链接、自动访问、提示注入载体和敏感信息泄露风险。
    
- A、B 主要是规范化，不是安全核心手段。
    
- F 会改变语义，不属于安全清洗。
    

**知识点：** 输入安全清洗包括长度限制、标签过滤、URL 抽象、白名单校验、输出转义等。  
**扩展讲解：** URL 替换不只是防恶意链接，还能防止自动访问不可信地址、SSRF、日志污染和 token 泄露。

### 8. 第170题：百炼平台的主要适用场景

**题目：** 百炼平台的主要适用场景是？  
A. 闭源模型的低成本高并发部署  
B. 边缘计算任务  
C. 长期稳定的私有化服务  
D. 开源模型的本地部署

**参考答案：** **A**。  
**选项解析：**

- A 正确：百炼是全托管 MaaS 平台，免运维、按需调用，支持高并发和成本优化。
    
- B 错误：百炼是中心化云托管平台，不是边缘计算平台。
    
- C 不是主要默认场景：百炼专属版可私有化，但不是标准百炼的主要定位。
    
- D 错误：百炼核心是云端托管调用，不是本地部署。
    

**知识点：** 百炼聚合通义千问及第三方模型，通过 API 提供托管模型服务。  
**扩展讲解：** “部署闭源模型”在百炼语境下通常指调用平台托管的闭源模型服务，而不是下载权重本地安装。

### 9. 第172题：端云协同部署的核心优势

**题目：** 端云协同部署的核心优势是？  
A. 完全免除云端依赖  
B. 平衡计算效率与用户体验  
C. 降低硬件采购成本  
D. 提高数据隐私等级

**参考答案：** **B**。  
**选项解析：**

- A 错误：端云协同仍依赖云端。
    
- B 正确：端侧低延迟轻量处理，云端强算力复杂处理，平衡效率和体验。
    
- C 不是核心优势。
    
- D 有部分相关性，但不是最概括的核心优势。
    

**知识点：** 端云协同 = 端侧轻量/低延迟/隐私敏感处理 + 云端大算力/复杂模型处理。  
**扩展讲解：** 典型例子是手机语音助手：唤醒词和简单指令端侧做，复杂语义理解和内容生成云端做。

### 10. 第173题：端云协同部署的优势

**题目：** 端云协同部署的优势有哪些？  
A. 完全替代本地部署  
B. 复杂任务上传云端处理  
C. 边缘设备处理简单任务，降低延迟  
D. 减少云端带宽压力

**参考答案：** **B、C、D**。  
**选项解析：**

- A 错误：不是完全替代本地部署。
    
- B 正确：云端承担复杂任务。
    
- C 正确：边缘处理简单任务降低延迟。
    
- D 正确：大量数据端侧处理，减少上传带宽和云端负载。
    

**知识点：** 端云协同强调分工，不是单方面替代。  
**扩展讲解：** 优势包括低延迟、带宽节省、云端弹性算力、隐私敏感数据少上传等。

### 11. 第75题：ROUGE 分数描述

**题目：** 关于 ROUGE 分数，哪些描述正确？  
A. ROUGE-1 关注单个词的重叠  
B. 仅适用于翻译任务  
C. ROUGE-L 基于最长公共子序列  
D. ROUGE-P 是精确率指标

**参考答案：** **A、C、D**。  
**选项解析：**

- A 正确：ROUGE-1 基于一元词重叠。
    
- B 错误：ROUGE 主要用于摘要，也用于文本生成、翻译、问答等。
    
- C 正确：ROUGE-L 使用最长公共子序列。
    
- D 正确：`-P` 表示 Precision 精确率。
    

**知识点：** ROUGE 衡量生成文本与参考文本的重叠程度，常见有 ROUGE-N、ROUGE-L、ROUGE-P/R/F 等。  
**扩展讲解：** ROUGE 偏重召回和内容覆盖；精确率变体关注生成内容中有多少与参考匹配。实际评估常与 BLEU、BERTScore、人工评估结合。

## 三、总体易错点总结

1. **流式输出 ≠ 流式输入**：第165题 E 的“长文本输入”表述不严谨。
    
2. **“全面识别”不等于“单次全量输出”**：第148选 D，但实际工程要分类型复核；第152说明单次全量易遗漏。
    
3. **抢占式实例核心是“低成本 + 可中断恢复”**：适合批处理，不适合数据库等有状态高稳定业务。
    
4. **安全清洗要区分“规范化”和“安全控制”**：小写、emoji 替换不是核心安全手段。
    
5. **百炼的“部署闭源模型”是托管调用，不是下载权重本地部署**。
    
6. **端云协同不是替代本地或云端，而是分工平衡**。
    
7. **ROUGE 不是只用于翻译**，其核心场景是摘要和文本生成评估。
