## 一、选择题错题整理

### 1. 时效性新闻总结方案选择

**题目**：  
你写了一个提示词“请用适合简报的形式，以每篇100字的篇幅总结今早的十大新闻”，你希望大模型能按照提示词完成任务，以下哪些方案可行？

**选项**：  
A. 整理历史新闻库，构建一个 RAG 应用，让大模型回答时参考知识库中的新闻  
B. 设计提示词，结合 function call，让大模型回答时效性问题时，调用搜索工具  
C. 使用阿里云百炼平台的 qwen-plus，并且调用 API 时设置 `enable_search=True`

**正确答案**：**B、C**

**解析**：  
题目强调“今早的十大新闻”，对**时效性**要求很高。

- A 使用“历史新闻库”构建 RAG，知识库可能未及时更新到今早新闻，无法保证时效性和完整性。
    
- B 通过 function call 调用搜索工具，可以获取最新新闻。
    
- C 阿里云百炼 qwen-plus 设置 `enable_search=True` 可开启联网搜索，获取实时信息。
    

**易错点**：RAG 知识库不等于实时联网搜索；历史库无法解决“今早”这种强时效问题。

### 2. `ask_llm_route` 无法识别问题类型时返回什么

**题目**：  
在 `ask_llm_route` 函数中，如果问题类型无法识别，会返回什么？

**选项**：  
A. `reviewed_prompt`  
B. `translate_prompt`  
C. `query_engine`  
D. `rag.ask`

**正确答案**：**D. `rag.ask`**

**解析**：  
`ask_llm_route` 是问题路由函数，根据问题类型返回对应处理方式。  
如果无法识别问题类型，通常会走默认兜底分支，交给通用 RAG 问答流程处理，即返回 `rag.ask`。

**易错点**：不要把路由函数理解成直接回答问题的函数，它只负责“分发”。

### 3. 不属于 RAG“建立索引”阶段的步骤

**题目**：  
以下选项中，不属于 RAG 工作流程中“建立索引”阶段的步骤的是哪一项？

**选项**：  
A. 将文档解析为纯文本  
B. 将长文本切成更小的片段  
C. 将用户问题转换为向量表示  
D. 将文本片段转换为向量表示

**正确答案**：**C. 将用户问题转换为向量表示**

**解析**：  
RAG 建立索引阶段通常包括：

1. 文档解析为纯文本
    
2. 长文本切分为小片段
    
3. 文本片段向量化
    
4. 存入向量数据库
    

而“将用户问题转换为向量表示”属于**查询/检索阶段**，不是建立索引阶段。

**易错点**：索引阶段处理的是“文档”，查询阶段处理的是“用户问题”。

### 4. Ragas 中仅评估生成阶段的性能指标

**题目**：  
Ragas 包含多种评测指标，其中 `faithfulness`、`answer_relevancy`、`context_recall`、`context_precision` 指标中，哪个指标仅评估生成阶段的性能？

**选项**：  
A. `context_precision`  
B. `faithfulness`  
C. `context_recall`  
D. `answer correctness`

**正确答案**：**B. `faithfulness`**

**解析**：

- `faithfulness`（忠实度）：评估生成答案是否忠实于检索到的上下文，是否出现幻觉，属于**生成阶段**指标。
    
- `context_precision` / `context_recall`：评估检索到的上下文质量，属于**检索阶段**指标。
    
- `answer correctness`：评估最终答案与标准答案的匹配程度，通常属于**端到端评估**。
    

**易错点**：注意区分检索阶段、生成阶段和端到端评估。

### 5. LlamaIndex 中如何修改召回文本段个数

**题目**：  
通过 LlamaIndex 创建 RAG 应用时，编写了如下代码，这段代码中，如何修改召回文本段的个数？

**选项**：  
A. `from_documents[similarity_top_k]`  
B. `as_query_engine(similarity_top_k)`  
C. `query_engine.query(similarity_top_k)`  
D. `streaming_response.print_response_stream(similarity_top_k)`

**正确答案**：**B. `as_query_engine(similarity_top_k)`**

**解析**：  
在 LlamaIndex 中，创建查询引擎时可以通过 `as_query_engine()` 传入 `similarity_top_k` 参数，指定召回文本段数量，例如：

python

query_engine = index.as_query_engine(similarity_top_k=5)

其他选项：

- A：`from_documents` 用于构建索引。
    
- C：`query()` 用于执行查询。
    
- D：`print_response_stream()` 用于打印流式响应。
    

**易错点**：`similarity_top_k` 应设置在查询引擎创建阶段，而不是查询执行阶段。

## 二、相关知识点巩固

### 1. `ask_llm_route` 是什么

`ask_llm_route` 通常是一个**问题路由函数**，也可以理解为“意图分发器”。  
它根据用户输入的问题判断任务类型，然后返回对应的处理方式，例如：

- 提示词审查类 → `reviewed_prompt`
    
- 翻译类 → `translate_prompt`
    
- 查询引擎类 → `query_engine`
    
- 无法识别或通用问答 → `rag.ask`
    

简化逻辑：

python

def ask_llm_route(question):
    if is_review_question(question):
        return reviewed_prompt
    elif is_translate_question(question):
        return translate_prompt
    elif is_query_engine_question(question):
        return query_engine
    else:
        return rag.ask

**作用**：让不同问题走不同流程，提高回答准确性和效率。

### 2. `answer_correctness` 详解

`answer_correctness` 是 Ragas 中用于**端到端评估**的指标，衡量生成答案与标准答案（Ground Truth）的匹配程度。

**计算原理**：  
由“事实性”和“语义相似度”加权融合。

1. **事实性（Factual Correctness）**  
    将答案拆解为事实陈述，分类为：
    
    - TP：生成答案和标准答案都出现的事实
        
    - FP：只在生成答案中出现的事实（幻觉/错误）
        
    - FN：只在标准答案中出现、生成答案遗漏的事实
        
    
    计算 F1 分数：
    
    F1=∣TP∣∣TP∣+0.5×(∣FP∣+∣FN∣)F1=∣TP∣+0.5×(∣FP∣+∣FN∣)∣TP∣​
2. **语义相似度（Semantic Similarity）**  
    计算生成答案与标准答案的向量嵌入之间的余弦相似度。
    
3. **最终得分**  
    默认权重为 `[0.75, 0.25]`，即事实性占 75%，语义相似度占 25%。
    

**与 `answer_accuracy` 的区别**：

- `answer_correctness` 基于陈述分解和分类，可解释性更高，需要 3 次 LLM 调用。
    
- `answer_accuracy` 使用双法官系统，需要 2 次独立判断，可解释性较低。
    

**使用示例**：

python

from datasets import Dataset
from ragas.metrics import answer_correctness
from ragas import evaluate
data_samples = {
    'question': ['When was the first super bowl?'],
    'answer': ['The first superbowl was held on Jan 15, 1967'],
    'ground_truth': ['The first superbowl was held on January 15, 1967']
}
dataset = Dataset.from_dict(data_samples)
score = evaluate(dataset, metrics=[answer_correctness])
print(score.to_pandas())

### 3. LlamaIndex 设置 `similarity_top_k` 示例与官方文档

**示例代码**：

python

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
# 1. 加载文档并构建索引
documents = SimpleDirectoryReader("./docs").load_data()
index = VectorStoreIndex.from_documents(documents)
# 2. 创建查询引擎，设置召回3个文本段
query_engine = index.as_query_engine(
    similarity_top_k=3,
    response_mode="compact",
    verbose=True
)
# 3. 执行查询
response = query_engine.query("你的问题")

**官方文档与来源**：

- LlamaIndex 官方文档 Usage Pattern：展示 `as_query_engine` 基本用法及底层检索器配置。
    
- 官方示例 10K Analysis：代码中明确使用 `lyft_index.as_query_engine(similarity_top_k=3)`。
    
- GitHub Issue #17283：提到通过 `similarity_top_k` 控制召回节点数量。
    

**参数说明**：

- `similarity_top_k`：控制检索阶段返回的文本段数量，默认通常为 1 或 2。
    
- `response_mode`：控制如何合成最终答案，如 `compact`、`tree_summarize` 等。

## 三、复习提示

1. **时效性问题**优先考虑联网搜索或 function call，而不是历史知识库 RAG。
    
2. **路由函数**无法识别时通常走默认 `rag.ask`。
    
3. **RAG 建立索引阶段**处理文档；**查询阶段**才处理用户问题向量化。
    
4. **Ragas 生成阶段指标**重点记 `faithfulness`；检索阶段记 `context_precision`、`context_recall`。
    
5. **LlamaIndex 召回数量**通过 `as_query_engine(similarity_top_k=...)` 设置。
    
6. `answer_correctness` 是端到端指标，结合事实 F1 与语义相似度，可解释性强。
