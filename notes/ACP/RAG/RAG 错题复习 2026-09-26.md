### 题目 1：RAG 建立索引阶段的主要步骤

**题目：**  
在 RAG 应用的建立索引阶段，主要步骤包括哪些？

**选项：**

- A. 将文件内容分割并转化为多维向量
    
- B. 使用专用 Embedding 模型
    
- C. 结合向量存储保留文本的语义信息
    
- D. 增加模型的训练数据
    

**正确答案：** A、B、C  
**题库答案：** 同正确答案  
**解析：**

- A：文档切分 + 向量化，是索引阶段核心。
    
- B：Embedding 模型负责文本到向量的编码。
    
- C：向量数据库存储向量，保留语义信息供检索。
    
- D：增加训练数据属于模型训练/微调，不属于 RAG 索引阶段。

### 题目 2：流式输出相比非流式输出的优势

**题目：**  
在通过 LlamaIndex 创建 RAG 应用时，以下关于流式输出相比于非流式输出的优势的说法正确的有哪些？

**选项：**

- A. 能够提升大模型回复的效果
    
- B. 能够加快大模型回复的速度
    
- C. 能够给用户带来良好的阅读体验
    
- D. 如果返回的内容很长可以逐步返回结果，避免超时
    

**正确答案：** C、D  
**题库答案：** 同正确答案  
**解析：**

- C：边生成边显示，用户无需等待全部完成，体验更好。
    
- D：长文本分块返回，降低一次性等待和超时风险。
    
- A：流式不改变模型生成质量。
    
- B：流式不加快模型推理速度，只改善“感知延迟”。
    

**补充：** stream 不是模型控制参数，而是响应传输模式。真正控制模型的是 temperature、top_p、max_tokens 等。

### 题目 3：RAG 检索生成阶段的主要步骤

**题目：**  
在 RAG 应用中，检索生成阶段的主要步骤包括哪些？

**选项：**

- A. 生成
    
- B. 文档解析
    
- C. 文本分段
    

**正确答案：** A  
**题库答案：** A、B ⚠️  
**解析：**

- 标准 RAG 划分：
    
    - 建立索引阶段：文档解析、文本分段、向量化、入库。
        
    - 检索生成阶段：检索、重排/过滤、生成。
        
- 因此严格来说只有 A 属于检索生成阶段。
    
- 题库若选 B，可能是把检索后对文档片段的解析/处理也算作“文档解析”，但不符合主流定义。
    

**备注：** ⚠️ 题库答案可能有误，或阶段定义不同。

### 题目 4：大模型内容安全治理措施

**题目：**  
在大模型的内容安全治理中，哪些措施可以防止生成非法或不当内容？

**选项：**

- A. Query 风险识别
    
- B. 基于知识库的搜索增强
    
- C. Response 风险识别
    
- D. 标准回答预置
    

**正确答案：** A、C、D  
**题库答案：** A、B、C、D ⚠️  
**解析：**

- A：输入侧拦截风险请求。
    
- C：输出侧检测并拦截不当内容。
    
- D：高风险问题用合规标准答案兜底。
    
- B：知识库增强主要用于提升准确性和可溯源性，本身不是专门的安全模块。若知识库经审核，可间接降低风险，但严格说不属于直接安全措施。
    

**备注：** ⚠️ 题库把 B 也算作安全治理，属于广义理解。

### 题目 5：影响 RAG 系统性能的因素

**题目：**  
以下哪些因素会影响 RAG 系统的性能？

**选项：**

- A. 查询语句的表达方式

**题库答案：** 同正确答案

**补充：**  
查询语句表达方式包括：措辞与术语、句式语法、语义清晰度、信息量长度、多轮上下文、意图约束、语言领域风格等。

### 题目 6：API KEY 配置环境变量的原因

**题目：**  
在通过 API 开发 RAG 应用时，一般会将 API KEY 配置环境变量，以下选项中关于其原因的解释正确的有？

**选项：**

- A. 防止 KEY 泄漏被 SDK 读取和使用
    
- B. 环境变量会自动被 SDK 读取和使用
    
- C. 环境变量可以加快程序的运行速度
    
- D. 配置为环境变量可以减少代码的行数
    

**正确答案：** B、D  
**题库答案：** A、B ⚠️  
**解析：**

- B：很多 SDK 默认从环境变量读取 KEY（如 `OPENAI_API_KEY`）。
    
- D：SDK 自动读取后，无需在代码中显式传参，代码更简洁。
    
- A：环境变量降低 KEY 硬编码泄漏风险，但 SDK 仍需读取和使用，表述不严谨。
    
- C：环境变量不影响运行速度。
    

**备注：** ⚠️ 题库选 A、B，A 有歧义，但按“防止硬编码泄漏”可解释。

### 题目 7：优化文档切片方法的有效思路

**题目：**  
在大语言模型 RAG 应用的基本工作流程中，以下哪些是优化文档切片方法的有效思路？

**选项：**

- A. 将所有文档合并成一个大文件，以便一次性加载和处理
    
- B. 按照 markdown 文档的结构进行切片，保留文档的原始结构信息
    
- C. 对于独立的标题、段落、单元格内容，在切片时补充语义信息
    
- D. 尽量将文档切片成等长的文本块，方便后续的向量化处理
    
- E. 根据用户提问的习惯和可能的提问方式进行切
    
- F. 使用更复杂的文档解析器，例如支持表格和图片解析的解析器
    

**正确答案：** B、C、E、F  
**题库答案：** 同正确答案  
**解析：**

- B：结构感知切片，保留层级。
    
- C：补充标题、章节等上下文，提升语义完整性。
    
- E：以查询为中心设计切片。
    
- F：解析是切片的前置步骤，更好的解析器能保留表格、图片、版面结构，从而优化切片。
    
- A、D：错误或非优化思路。
    

**补充：** 切片不是孤立动作，解析质量直接决定切片质量。

### 题目 8：改善大模型事实性错误的方法

**题目：**  
当发现大模型生成的内容存在事实性错误时，以下哪些方法可以有效改善这一问题？

**选项：**

- A. 采用 RAG 架构，引入外部知识源
    
- B. 在提示词中要求模型注明信息来源
    
- C. 使用思维链（CoT）提示，让模型展示推理过程
    
- D. 对模型进行领域相关的微调
    
- E. 完全依赖模型的内置知识，不进行任何干预
    

**正确答案：** A、B、D  
**题库答案：** B、C、D ⚠️  
**解析：**

- A：RAG 引入可靠外部知识，是缓解事实错误的核心手段。
    
- B：要求注明来源，增加可追溯性，减少编造。
    
- D：领域微调可注入领域知识，减少领域内错误。
    
- C：CoT 主要提升多步推理，不直接提供事实知识，不能保证事实正确。
    
- E：明显错误。
    

**备注：** ⚠️ 题库排除 A 非常不合理，选 C 有争议。标准技术理解应为 A、B、D。

### 题目 9：提升检索精度的方法

**题目：**  
开发者在优化 RAG 应用时，发现“检索到的文本段与用户问题相关性低”（精度低）。以下哪些措施可有效提升检索精度？

**选项：**

- A. 提高检索的相似度阈值（如从 0.6 升至 0.8）
    
- B. 优化文本分块策略，按语义逻辑分块
    
- C. 对输入问题进行语义增强（如补充“领域：电商，任务：售后”等上下文）
    
- D. 减少向量数据库中的文档数量，删除无关文档
    

**正确答案：** A、B、C、D  
**题库答案：** 同正确答案  
**解析：**

- A：提高阈值过滤低相关结果，提升精度（但可能降低召回）。
    
- B：语义分块使主题更集中。
    
- C：语义增强让查询向量更准确。
    
- D：删除无关文档减少噪声。

### 题目 10：电商智能导购系统部署方案

**题目：**  
某开发者需开发一款电商智能导购系统，要求模型能根据用户历史购买记录、浏览行为推荐精准商品，且响应延迟 ≤500ms。以下哪种模型部署方案最适配？

**选项：**

- A. 选用 13B 参数的开源大模型本地部署
    
- B. 选用 70B 参数的闭源大模型 API 调用
    
- C. 选用 3B 参数的轻量化模型结合向量数据库
    
- D. 直接使用通用大模型，不做任何优化
    

**正确答案：** C  
**题库答案：** 同正确答案  
**解析：**

- C：3B 轻量模型推理快，向量数据库快速检索用户行为和相似商品，兼顾延迟与个性化。
    
- A、B：13B/70B 延迟通常难以稳定 ≤500ms。
    
- D：无优化，无法满足要求。
    

**补充：** 13B/70B 响应时间参考：

- 13B 在 A100 + INT8 量化下约 320ms；RTX 4090 上 TTFT 约 963ms。
    
- 70B 单次请求总延迟常在数秒到数十秒，难以满足 ≤500ms。

### 题目 12：提升 RAG 检索器性能的技术

**题目：**  
以下哪些技术可以用于提升 RAG 系统中检索器的性能？

**选项：**

- A. 优化文本切分（Chunking）策略
    
- B. 使用更先进的嵌入（Embedding）模型
    
- C. 实施重排序（Re-ranking）机制
    
- D. 增加检索返回的结果数量
    
- E. 结合关键词检索和向量检索
    

**正确答案：** A、B、C、E  
**题库答案：** 同正确答案  
**解析：**

- A：合理切片减少噪声。
    
- B：更好的 Embedding 提升语义匹配。
    
- C：重排序精细排序，提升 top-k 精度。
    
- E：混合检索兼顾关键词与语义。
    
- D：单纯增大 top-k 会引入噪声，降低精度，不是有效优化。

### 题目 14：多模态文档处理系统的必要组件

**题目：**  
在构建多模态文档处理系统时，需要处理包含文字、表格、图片的复杂文档。以下哪些技术组件是必要的？

**选项：**

- A. 文档解析模块，提取文本、表格和图片
    
- B. 多模态理解模型，处理图文混合内容
    
- C. 向量数据库，存储文档片段嵌入

### 题目 15：RAG 问答系统最终答案质量的影响因素

**题目：**  
在构建一个基于 RAG 的问答系统时，以下哪些因素会直接影响最终答案的质量？

**选项：**

- A. 原始知识库文档的质量和覆盖面
    
- B. 文档切分和向量化嵌入的策略
    
- C. 向量检索时使用的相似度算法和阈值
    
- D. 提供给大模型的提示词模板设计
    
- E. 大模型本身的理解和生成能力
    

**正确答案：** A、B、C、D、E  
**题库答案：** A、B、D、E ⚠️  
**解析：**

- A：知识库是事实来源。
    
- B：切片与 Embedding 影响召回质量。
    
- C：相似度算法和阈值直接决定召回哪些片段，从而直接影响生成上下文。
    
- D：提示词决定模型如何使用上下文。
    
- E：模型能力决定理解与生成质量。
    

**备注：** ⚠️ 题库排除 C 不合理。C 是检索阶段关键参数，检索结果直接输入生成阶段，应影响最终答案质量。

## 三、核心结论

1. **RAG 是端到端链路**：数据 → 索引 → 检索 → 生成，任一环节都影响最终质量。
    
2. **检索阶段的关键参数（相似度算法、阈值、top-k）会直接影响生成上下文**，不应被忽视。
    
3. **流式输出不提升模型能力**，只改善感知延迟和用户体验。
    
4. **内容安全治理需覆盖输入、输出和兜底策略**；知识库增强可间接降低风险，但并非专门安全模块。
    
5. **多模态文档处理系统 ≠ RAG**，只有结合检索与生成时才是多模态 RAG。
    
6. **遇到题库答案与标准技术理解冲突时，建议以技术逻辑为准，并与助教确认**。
