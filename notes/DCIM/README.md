## 三条使用原则

1. **先框架后细节**：每章开头的「知识地图」先背下来，再看细节；考试 70 道单选 + 30 道多选，考的是覆盖面而不是深度推导。
2. **周测必须闭卷**：周测正确率 < 80% 不要进下一周，先回炉当周资料里标了「高频考点」的小节。
3. **错题只记一件事**：每道错题记下「错在哪个概念 + 正确说法一句话」，写进 [学习计划](学习计划.md) 末尾的错题台账，考前只看这张表。

## 让教练带你学（推荐）

不用自己记进度。在仓库根目录对 OpenCode 说：

```text
开始学习DCIM运维     → 打开当前周资料，给出本周目标与今天先读哪节
学完了               → 一次一题做口述知识检查，记录掌握程度
开始测试             → 给出本周周测（不含答案）
1A 2B 3C …           → 判分、讲错题、更新进度
进入下一周           → 仅在本周 ≥80% 时允许
查看进度             → 看总览与下一步
```

进度与成绩写在 [harness/progress.md](harness/progress.md)，规则见 [harness/README.md](harness/README.md)。硬规则：**周测不到 80%，教练不会让你进入下一周。**

## 考试速览（来自官方大纲）

- 形式：线下上机、闭卷，120 分钟
- 题量与分值：单选 70 题 + 多选 30 题，每题 1 分，满分 100 分
- 通过线：**80 分**（即最多错 20 题，容错率 20%）
- 权重：脊叶架构 20% ＞ 服务器硬件维修 / 服务器故障排查 / 项目管理 各 15% ＞ 服务器操作系统 / 三层网络 / 资产管理 各 10% ＞ 超大规模数据中心 5%
