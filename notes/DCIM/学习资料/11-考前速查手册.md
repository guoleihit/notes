## 三、排序类速记

### 3.1 数据中心生命周期

**规划设计 → 实施建设 → 测试验证 → 运营维护 → 优化改造 → 老化退出**

### 3.2 BGP 选路 13 步

**Weight → Local_Preference → 本地起源 → AS_PATH 最短 → Origin → MED 最小 → eBGP > iBGP → IGP 度量最小 → 多路径 → 最老 → RID 最小 → Cluster_List 最短 → 邻居 IP 最小**

### 3.3 STP 选举

**根桥（网桥 ID 最小）→ 根端口（到根开销最小）→ 指定端口（每网段最优）→ 其余阻塞**

### 3.4 停机维修后检查

**BIOS 识别 → 指示灯 → 进无盘 RAMOS 无刷屏 → 进系统 login 无刷屏 → 执行自动检查工具**

### 3.5 硬盘槽位判断

**HBA：lspci 判卡 → smartctl 取 SN → sas2ircu/sas3ircu 查槽位**
**RAID：lspci 判卡 → hpssacli / storcli64 看物理盘与 SMART**

### 3.6 PXE 引导

**DHCP（IP + next-server + filename）→ TFTP（pxelinux.0 / vmlinuz / initrd）→ HTTP（镜像 + ks.cfg）**

### 3.7 MPLS VPN 数据面

**PE 打内层（MP-BGP 分配）+ 外层（LDP 分配）→ P 交换 → 次末跳 PHP 弹外层 → 出 PE 按内层找 VRF → CE**

### 3.8 项目管理收尾

**合标 → 合法 → 完工 → 交付**

| 3 | 只有一条内存，随便插 | **单 CPU 必须插 CPU0（或编号首槽）** |

| 5 | swap 分区 = 内存的 1.5 倍 | 课件方案：**swap = 内存大小** |

## 五、考场执行清单

1. **两遍法**：第一遍只做有把握的（目标 60 题/40 分钟），标记不确定的；第二遍攻标记题。
2. **多选题**：逐项判断「对不对」，不选不确定项；特别注意题目问的是「属于」还是「不属于」。
3. **绝对化词**：出现「一定/必须/只能/全部」先怀疑，但课程中的硬性规定（CPU0、必须关机、必须书面记录变更）要认。
4. **数字题**：先回忆单位与量级（ms / s / Mbps / Gbps / %），再选。
5. **场景题**：先判断「部件/协议/阶段」，再套对应清单（如看到「多盘不识别」→ 背板；看到「卡在 init」→ MTU）。
6. 最后 15 分钟：检查答题卡是否有漏涂，复核所有标记题，不要改第一直觉（除非确认看错题）。
